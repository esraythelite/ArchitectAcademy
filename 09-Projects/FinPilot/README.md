# FinPilot

FinPilot is an AI-powered investment platform developed as part of the
Architect Academy program.

The project is used to explore real-world software architecture concepts such as:

- Modular Monolith
- Domain-Driven Design
- Distributed Systems
- Event-Driven Architecture
- Kafka
- Redis
- Observability
- Docker
- Kubernetes
- AI Engineering
- RAG
- AI Agents
- MCP

## Current Status

Project initialization and architecture bootstrap.

## Architecture

FinPilot starts as a Modular Monolith.

The initial business modules are:

- Identity
- Onboarding
- Customer
- Portfolio
- Trading
- Notification
- AI
