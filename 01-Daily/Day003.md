## Architecture Decisions

### Start with a Modular Monolith

FinPilot will initially be developed as a Modular Monolith.

The main reason is that the domain boundaries are not mature enough yet.

Starting directly with microservices would introduce unnecessary complexity such as:

- Network communication
- Distributed transactions
- Service discovery
- Deployment complexity
- Observability complexity
- Message consistency

The modules will initially live inside the same deployment unit.

If necessary, some modules can later be extracted into independent services.
